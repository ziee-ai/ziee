- **TEST-2** (tier: integration) [acceptance] [invariant: INV-2] [covers: ITEM-1] file: `src-app/server/tests/agent/task_list_test.rs` — asserts: the counterpart — a run terminating with ALL its task rows already `completed` is left byte-for-byte untouched (every row still `completed`, none rewritten to `abandoned`); reconciliation never claims unfinished work was done.
- **TEST-3** (tier: integration) [acceptance] [invariant: INV-3] [covers: ITEM-4, ITEM-5] file: `src-app/server/tests/agent/task_list_test.rs` — asserts: the non-happy terminal paths reconcile.
